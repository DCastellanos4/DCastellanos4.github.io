# 🕹️ Portfolio Retro - David Castellanos

A modern yet retro-inspired professional portfolio website built with HTML5, Bootstrap 5, and vanilla JavaScript.

---

## 🎨 Features

* **Responsive Design**: Built with Bootstrap 5 for seamless mobile, tablet, and desktop experiences.
* **Dark/Light Mode Toggle**: Switch between dark and light themes with persistent user preference.
* **Retro Aesthetic**: Custom styling with a nostalgic 80s/90s design-inspired visual.
* **Smooth Navigation**: Sticky navigation bar with smooth scrolling to different sections.
* **Multi-language Support**: Interface available in Spanish (es) with potential for expansion.
* **Fast & Lightweight**: No dependencies beyond Bootstrap icons and CDN libraries.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Custom Retro Styles)
* **Framework**: [Bootstrap 5](https://getbootstrap.com/)
* **Logic**: Vanilla JavaScript
* **Icons**: Bootstrap Icons

## 🚀 Getting Started

### Prerequisites
* A modern web browser (Chrome, Firefox, Safari, Edge).
* [Node.js](https://nodejs.org/) (optional, for local development).

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/DCastellanos4/portfolio-retro.git](https://github.com/DCastellanos4/portfolio-retro.git)
    cd portfolio-retro
    ```

2.  **Open in browser**
    Simply open `index.html` in your browser, or use a local server:
    ```bash
    npx http-server
    ```

3.  **Customize your content**
    * Edita `index.html` para añadir tu información personal.
    * Modifica `css/style.css` para ajustes de diseño.
    * Actualiza `js/main.js` para funcionalidades adicionales.
